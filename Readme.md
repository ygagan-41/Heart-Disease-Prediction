#  Heart Disease Prediction

A Machine Learning web application built with Python and Streamlit to predict the likelihood of heart disease based on user-provided health information.

## Live Demo

**Try the application here:**

🔗 https://heart-disease-prediction-86z.streamlit.app/

## Project Overview

This project demonstrates how Machine Learning can be used to analyze health-related data and make heart disease predictions through a simple, interactive web interface.

Users can enter the required health parameters and receive a prediction from the trained machine learning model.

## ✨ Features

- 🩺 Heart disease prediction using Machine Learning
- 🖥️ Interactive web interface built with Streamlit
- 📊 User input for health-related parameters
- ⚡ Fast predictions using a trained model
- 🌐 Deployed online for easy access

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Web Framework:** Streamlit
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Model Persistence:** joblib
- **Deployment:** Streamlit Community Cloud


## Learning Objectives

This project helped me explore:

- Building a Machine Learning prediction application
- Integrating a trained model with a web interface
- Using Python libraries for data processing and prediction
- Deploying a Python application using Streamlit
